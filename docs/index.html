为什么选择南阳虚拟Win？

从芯片底层到用户交互，每一个细节都为手机端 Windows 体验精心设计。

🔧

UEFI / SeaBIOS 双 BIOS

支持现代 UEFI 启动与传统 Legacy BIOS，灵活适配不同 Windows 镜像需求。

🛡️

TPM 2.0 完整支持

内置软件 TPM 2.0 模拟器，满足 Windows 11 安装要求的可信平台模块验证。

📱

ARM 原生 + x86 模拟

骁龙/联发科/麒麟芯片原生 ARM64 运行；x86 软件通过 QEMU TCG 指令集模拟运行。

🔌

OTG USB 设备直通

插入 U盘或外设后自动识别，驱动直接穿透至虚拟机内部，即插即用。

💾

VMDK 磁盘格式

原生支持 VMware VMDK 薄置备磁盘，兼容主流虚拟化产品生成的虚拟硬盘。

⚡

芯片专属性能优化

针对高通 Krait/Cortex-A、联发科 Helio/Dimensity、华为麒麟自动适配 CPU 模型与加速器参数。

🔒

ISO 镜像 SHA-256 验签

加载 ISO 时自动比对哈希值，确保镜像未被篡改，保障系统纯净安全。

🔋

电量监控与后台管理

实时显示电池状态与温度，虚拟机运行时自动申请忽略电池优化限制。

系统要求与支持范围

了解更多细节，帮助你判断自己的设备是否适合运行。

操作系统Android 8.0 (API 26) 及以上
处理器架构arm64-v8a（骁龙 / 联发科 / 麒麟）
BIOS 固件UEFI (OVMF) / SeaBIOS（可选）
TPM 版本TPM 2.0（软件模拟）
虚拟磁盘格式VMware VMDK（薄置备）
网络模式NAT / 桥接 / 无网络
USB 支持OTG 设备直通（需授权）
最低内存需求2 GB RAM（推荐 4 GB+）
最低磁盘空间10 GB 可用空间
引擎QEMU-system-arm / qemu-system-x86_64 (TCG)
